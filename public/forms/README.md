# Hardcopy Registration Form PDFs

Place your PDF files in this folder (`public/forms/`):

1. `M1_Student_Workshop_Form.pdf` - Registration form for Module 1 (Student Workshop)
2. `M2_Train_The_Teacher_Form.pdf` - Registration form for Module 2 (Train-the-Teacher ToT)
3. `M3_Hackathon_Form.pdf` - Registration form for Module 3 (School-Level Competition & Hackathon)

Once placed here, Vite will automatically serve them at:
- `/forms/M1_Student_Workshop_Form.pdf`
- `/forms/M2_Train_The_Teacher_Form.pdf`
- `/forms/M3_Hackathon_Form.pdf`

Alternatively, you can paste direct Cloudinary / Google Drive download URLs in `src/lib/forms.js`.
